          GEOMETRY_DISPATCH
          
        

        

          15 Layout Algorithms.
        

        

          Hierarchical Sugiyama, Force-Directed, Tree, Radial, Grid, and Cycle-Aware feedback arc set breakers designed for deterministic layout stability.
        

      


      

        

          

          
Sugiyama Hierarchical

          
Layered ranking with barycenter and median crossing minimization. Handles dense flowcharts and deep dependency cascades.

        

        

          

          
Cycle-Aware Feedback Arc

          
Detects back-edges and recursive loops automatically, reversing them during ranking to ensure strict acyclic layering without tangle.

        

        

          

          
Incremental Pipeline

          
Layout stages cache prior node bounds and rank assignments. Typing edits compute in sub-millisecond frames.
